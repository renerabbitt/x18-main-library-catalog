# X18 Main Library Catalog

A standalone, searchable catalog for the Rabbitt Design Chief Architect X18 Main Library.

- 6,728 library items
- Folder navigation and breadcrumbs
- Searchable folders and item names
- Shareable folder and item links

The catalog data was generated from `261019-Main.calibz`. It does not use or compare against `User_Library.calib`.
